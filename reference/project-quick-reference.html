AI Workbench 项目参考手册

这是 AI Workbench 项目的快速参考手册，包含关键信息和常用命令。

技术栈

前端: React 18 + TypeScript + Vite

后端: Tauri v2 + Rust

状态管理: Zustand + localStorage

样式: 纯 CSS（无 Tailwind）

图标: Lucide React

常用命令

# 安装依赖 npm install # 开发模式 npm run dev # 构建生产版本 npm run build # 运行调试版本 Start-Process "D:\ai_project\ai-workbench\src-tauri\target\debug\ai-workbench.exe" # 构建 Rust 后端（在 src-tauri 目录） cargo build --release

目录结构

src/ - 前端源码

src-tauri/ - Rust 后端

dist/ - 构建产物

node_modules/ - 依赖包

核心模块

模块 路径 功能
状态管理 src/core/store.ts Zustand store，管理所有应用状态
类型定义 src/core/types.ts TypeScript 类型定义
数据库 src/core/sqlite.ts SQLite 模块（预留）
存储工具 src/core/storage.ts 存储相关工具函数

主要组件

组件 路径 功能
AccountManager src/components/AccountManager.tsx Git 账号管理
QuickSwitch src/components/QuickSwitch.tsx 快速切换 Git 配置
RepoConfig src/components/RepoConfig.tsx 仓库配置管理
HostsManager src/components/HostsManager.tsx 系统 hosts 文件管理
PluginBrowser src/components/PluginBrowser.tsx 插件浏览器
CursorManager src/components/CursorManager.tsx Cursor 账号管理
AIAssistant src/components/AIAssistant.tsx AI 助手聊天界面

Rust 后端命令

Git 相关:

  • set_git_config(scope, name, email)
  • set_repo_git_config(repo_path, name, email)
  • get_git_config(scope?)

Hosts 相关:

  • read_system_hosts()
  • is_admin()
  • backup_hosts()
  • write_system_hosts(content)
  • list_host_backups()
  • restore_host_backup(path)

Plugin 相关:

  • download_web_plugin(url, id)
  • read_plugin_file(path)
  • delete_plugin_file(path)

数据存储

持久化: localStorage（通过 Zustand persist 中间件）

存储键:

  • git-accounts: Git 账号列表
  • git-repo-configs: 仓库配置列表
  • web-plugins: 插件列表
  • plugin-states: 插件状态
  • recent-projects: 最近项目
  • workbench-settings: 应用设置
