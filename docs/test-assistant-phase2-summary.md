## 使用方法

### 1. 添加测试项目
1. 打开 AI Workbench
2. 点击侧边栏"系统小工具" → "测试管理"
3. 点击"添加项目"
4. 选择项目路径（例如：`D:\my-react-app`）
5. 系统自动检测框架（Jest/Vitest/Cargo/PyTest/Go）
6. 点击"添加"

### 2. 扫描目录
1. 点击"扫描目录"
2. 选择一个包含多个项目的目录
3. 系统自动扫描并列出可测试项目
4. 点击"添加"按钮批量添加

### 3. 运行测试
1. 在项目列表中找到目标项目
2. 点击"运行测试"按钮
3. 等待测试完成（显示加载动画）
4. 查看测试结果（通过/失败数量、输出）

## 已知限制

1. **测试输出解析**：当前使用简单的正则表达式，可能不够精确
2. **不支持并发**：同一时间只能运行一个测试
3. **无测试历史查看**：虽然数据库支持，但 UI 未实现
4. **无测试配置编辑**：添加后无法编辑配置
5. **无批量操作**：无法批量运行或删除项目
