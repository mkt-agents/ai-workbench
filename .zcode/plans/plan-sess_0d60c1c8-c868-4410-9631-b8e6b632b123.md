# 快问（AI 问答）优化：缺陷修复 + 交互 + 布局

三个探索代理已完成全面分析（UI 层 / 数据管线层 / 样式与窗口架构），关键论断已逐一核验。按用户确认：三阶段全做，AskPanel/QuickAskApp 组件拆分本轮不做。

## 阶段 1 — 正确性/安全缺陷（6 项）

### 1.1 只读命令判定收紧（安全，最重要）
`src-tauri/src/agent.rs:461-479`：`command_is_readonly` 按前缀把 `git branch`、`git remote` 整族判为只读，导致 `git branch -D main`、`git remote remove origin`、`git remote set-url` 跳过用户审批直接执行。
- `git branch`：含 `-d`/`-D`/`-m`/`-M`/`--delete`/`--edit-description`/`--set-upstream-to` 任一独立 token 即非只读（`-a`/`-v`/`--list` 等查询参数保持只读）
- `git remote`：仅裸命令或后跟 `-v`/`--verbose` 只读；`add`/`remove`/`rename`/`set-url`/`prune` 非只读

### 1.2 command_blocked 子串误伤
`agent.rs:435-459`：`"rebase"`/`"--force"` 用 `contains` 匹配，`git log --grep=rebase` 被拦。
- 移出子串表，改 token 级判定：git 第二个 token == `rebase` 才拦；`--force`/`--force-with-lease` 仅作独立 arg token 拦
- 新增单测钉住：`git branch -D main` 需审批、`git remote remove origin` 需审批、`git log --grep=rebase` 放行且只读、`git push --force` 拦截、`git branch -a` 只读

### 1.3 send 双发竞态
`src/components/quickAsk/useAskStream.ts:169`：busy 是 state 非 ref，双击/同帧双 Enter 可并发两个 `agent_run` 同写一个仓库。
- 加 `busyRef`（与 agentStepsRef 同模式），send 入口先查 ref；busy 置位/复位处同步

### 1.4 busy 时删除当前会话 → 已删对话复活
`useAskSessions.ts:51-61` + in-flight `finishTurn` 会以新 session 重建刚删的对话。
- SessionHistory 中 busy 时禁用「当前活动会话」的删除按钮（其它会话不受影响）

### 1.5 Esc 关掉重命名中的历史面板
`SessionHistory.tsx:46`：重命名输入的 Esc 未 stopPropagation，冒泡到全局链把整个面板关掉。
- keydown 加 stopPropagation，只取消重命名

### 1.6 每次唤出窗口隐式打一次建议请求
`useNextSuggestion.ts`：effect 依赖 `model` 对象，`quick-ask-shown` → loadAIModels → 新数组 → identity 抖动 → 重跑生成。
- 依赖改 `model?.id`（model 对象走 ref 随渲染更新）+ lastKeyRef 同 key 不重复请求

## 阶段 2 — 交互优化（7 项）

### 2.1 tools 页签的代理审批入口
`QuickAskApp.tsx` busy-pill（~691-705）：`stream.agentApproval` 存在时扩展为「等待确认 · [允许] [拒绝]」（复用 `stream.decideAgent` 与既有 `agent.allow/deny` i18n）；否则保持「仍在执行 · 停止」。解决切页签后审批不可达、只能等 300s 超时自动拒绝。

### 2.2 busy 静默失败提示
`QuickAskApp.tsx`：新增轻量 hint（文案 + 2.5s 自动消失，复用/仿 `.quick-ask-hint` 样式）。触发点：busy 时 Ctrl+N、openSession 点会话（面板此时也不关）、runOpen。i18n 双语补 `busyHint`。

### 2.3 Esc 链补全与状态残留
`QuickAskApp.tsx:430-493`：
- openList 打开时 Esc 仅关建议列表（`openDismissedRef`，input 变化重置），插在 openPop 分支之前
- mode 切换 effect（489-493）补 `snippets.setSnippetOpen(false)` + `snippets.setParamTarget(null)`

### 2.4 去掉任务标签重复控件
`AskPanel.tsx:724-736` + CSS：删除 `.qa-task-tag`（任务状态由 qa-task-track 高亮承载，再次点击即取消），释放底栏第二行空间。

### 2.5 「继续」按钮去魔法字符串化
`AskPanel.tsx:362`：条件加 `turn.steps?.length > 0`（agent 回合才有持久化 steps），保留字符串匹配为第二条件，消除非代理轮误触发面。

### 2.6 填入剪贴板非空时追加
`QuickAskApp.tsx:~539`：`prev ? prev + "\n" + clip : clip`，不再静默无动作。

### 2.7 `/` 无片段不弹空面板
`useAskSnippets.ts:79-92`：无片段时 `syncSlashFromInput` 直接不开面板。
